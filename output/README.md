# output

号ごとの完成物を置く場所です。

例:

```txt
output/
  2026-05/
    draft/
      reporter1.md
      reporter2.md
      reporter3.md
    article.md
    sources.md
    newspaper.html
    newspaper-01.png
    newspaper-02.png
    newspaper-03.png
    newspaper.pdf
```

`draft/` は下書き置き場、`article.md` が最終原稿です。
