# 編集方針: 読者全員に響かせる

おさんぽマルシェ新聞は、読者数が少ないから一部に届けばよい、という姿勢では作らない。

本当に良い新聞なら、読者全員に何かしら響くはず、という前提で作る。

結果として、読者全員に同じ深さで響くとは限らない。
それでも、作る側は最初から読者を間引かない。
「何割かに伝わればよい」という打算で作らない。
読者全員に届けるつもりで書く。

大事にすること:

- 「34人のうち数人に届けばよい」と考えない。
- 才能の有無より、全力で届けようとする姿勢を大事にする。
- 読者全員の食卓、暮らし、買い物、体、畑へのまなざしに関係があるものとして書く。
- 反応が見えないことと、届かなくてよいことは違う。
- 作り手側の逃げとして「刺さる人だけに刺さればよい」を使わない。
- 写真だけ見る人にも、見出しだけ読む人にも、本文まで読む人にも、それぞれ引っかかるものを作る。
- 直売所の価値を、本気で読者全員に届ける。

合言葉:

読者全員の心に届くものを出す。
