# オラ文体・編集方針

## 目的

次稿を作るときに、書き手の「オラらしさ」を消しすぎないための共有メモ。

読みやすく整えることは大事だが、きれいにしすぎて普通の広報文にしない。

## 大事にする芯

- 一人称は基本的に「オラ」。
- 素材にある言葉、言い回し、違和感、笑い、迷いを先に見る。
- 文法を標準語へ直しすぎない。読みにくいところだけ少し整える。
- 難しい話は、畑、直売所、食卓、人情、暮らしの手触りへ戻す。
- 強い考えは断定で押し付けず、「オラにはそう見える」「そんな気がする」「だよな」くらいの余白を残す。
- 誰かを下げて正しさを作らない。人の違いは、畑で出会った知恵として扱う。
- 説明しきれない納得を残す。全部を解説してしまわない。
- 隠れ遊びや元ネタは、紙面の端や参考欄で小さく効かせる。

## オラ語の扱い

- 「だよな」「だな」「だよ」「だって」「なんだよなー」など、本人の語尾を残す。
- 「だ」「だが」「だよな」は、素材にあるときは味として残してよい。
- 方言っぽさを増やして作りすぎない。素材にない口癖を勝手に盛らない。
- 「オラは無知だから」系の言葉は、自虐ではなく前へ進む力として扱う。

## 紙面に出すときの判断

- 本音の根っこは残す。
- ただし、紙面で人を刺しすぎる表現は少し丸める。
- 編集判断の本音と、読者へ渡す言葉は分ける。
- 「今は投げない言葉」は、無理に使わず寝かせる。

## 例として残す言葉

- 未来の野菜は、遠くから来るとは限らない
- 野菜の値段って形や鮮度だけでなく、「どこから来たのか」も大切になるかもしれない話。
- 無知だったからこそ、ひたすら前進あるのみ！
- だってナンダカ、だってダッテなんだモン。
- 誰にもわからなくてよかった畑が、誰かの一歩を待つ場所になった。

最後の言葉は強いが、今すぐ使うとは限らない。時期が来るまで寝かせる。
